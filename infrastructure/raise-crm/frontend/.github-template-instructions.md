# Making This a GitHub Template Repository

If you want to push this to GitHub and use it as a template repository:

## 1. Create GitHub Repository

```bash
cd ~/Projects/nextjs-starter

# Create new repo on GitHub (via gh CLI or web interface)
gh repo create nextjs-starter --public --source=. --remote=origin

# Or manually:
# 1. Go to github.com/new
# 2. Create repository named "nextjs-starter"
# 3. Don't initialize with README (we already have one)
```

## 2. Push to GitHub

```bash
git remote add origin git@github.com:yourusername/nextjs-starter.git
git branch -M main
git push -u origin main
```

## 3. Enable Template Repository

1. Go to your repository on GitHub
2. Click **Settings**
3. Check **Template repository** under "General"
4. Save changes

## 4. Using the GitHub Template

Now anyone can use it:

```bash
# Method 1: GitHub UI
# Click "Use this template" button on GitHub

# Method 2: degit (from GitHub)
npx degit yourusername/nextjs-starter my-new-project
cd my-new-project
./setup.sh

# Method 3: GitHub CLI
gh repo create my-new-project --template yourusername/nextjs-starter
cd my-new-project
./setup.sh
```

## Benefits of GitHub Template

- ✅ One-click project creation
- ✅ No git history in new projects
- ✅ Easy to share with team
- ✅ Automatic updates possible
- ✅ Works with degit

## Local Usage (Without GitHub)

You can still use it locally without pushing to GitHub:

```bash
cp -r ~/Projects/nextjs-starter ~/Projects/my-new-project
cd ~/Projects/my-new-project
./setup.sh
```

Both methods work great! 🎉
